# Jeff Caldwell's Homebrew tap

macOS apps by [Jeff Caldwell](https://www.jeffcaldwell.ca/), installable with Homebrew.

```bash
brew tap jeffcaldwellca/tap
```

| App | Install | What it is |
|---|---|---|
| [Teleport](https://www.jeffcaldwell.ca/teleport/) | `brew install --cask teleport-ftp` | Native FTP, FTPS and SFTP client, with the `tport` CLI built in |
| [PortDrop](https://www.jeffcaldwell.ca/portDrop/) | `brew install --cask portdrop` | Menu-bar list of every process listening on a local TCP port |
| [macspanso](https://www.jeffcaldwell.ca/macspanso/) | `brew install --cask macspanso` | GUI for the espanso text expander |

Or install without tapping first, e.g. `brew install --cask jeffcaldwellca/tap/portdrop`.

Casks are updated automatically by each app's release workflow. Report app bugs in the app's
own repository.
